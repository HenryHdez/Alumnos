API: es una interfaz que permite que distintos sistemas se comuniquen entre sí
mediante reglas y formatos definidos para solicitar y enviar datos o servicios.

===============================================================================
Creación de un API con Docker
===============================================================================
La API permite:
- Crear (POST)
- Leer (GET)
- Actualizar (PUT / PATCH)
- Eliminar (DELETE)

docker rm -f restheart
docker rm -f mongo1
docker volume rm mongo1

docker network create redmongo

docker run -d --name mongo1 --hostname mongo1 --net redmongo -p 27017:27017 -v mongo1:/data/db mongo:latest --replSet rs0 --bind_ip_all

Nota: RestHEART funciona en modo replica

docker exec -it mongo1 mongosh

Dentro de mongosh ejecutar:

rs.initiate({
  _id: "rs0",
  members: [
    { _id: 0, host: "mongo1:27017" }
  ]
})

rs.initiate()
rs.status()

use admin

db.createUser({
  user: "admin",
  pwd: "admin123",
  roles: [
    { role: "root", db: "admin" }
  ]
})

RESTHeart expone MongoDB como API REST.

Se conecta a MongoDB usando la cadena:
mongodb://admin:admin123@mongo:27017/?authSource=admin

Comando:

docker run -d --name restheart --network redmongo -p 127.0.0.1:8080:8080 -e RHO="/http-listener/host->'0.0.0.0';/mclient/connection-string->'mongodb://mongo1:27017'" softinstigate/restheart

En el navegador:
http://127.0.0.1:8080/ping

O con curl en powershell:

curl http://127.0.0.1:8080/ping

NOTA:
RESTHeart usa autenticación.
Usuario por defecto:
- usuario: admin
- contraseña: secret

En Postman

--Crear coleccion
curl -u admin:secret -X PUT http://127.0.0.1:8080/items
--Agregar elemento
curl -u admin:secret -X POST http://127.0.0.1:8080/items
  {
    "name": "lapiz",
    "price": 1200
  }
--Consultar
curl -u admin:secret -X GET http://127.0.0.1:8080/items
--Actualizar
curl -u admin:secret -X  PUT http://127.0.0.1:8080/items/<id>

  {
    "name": "lapiz",
    "price": 1500
  }

--Eliminar
curl -u admin:secret -X DELETE http://127.0.0.1:8080/items/<id>
